# 7단계 — 커넥톰 배선 제약 + 가중치 학습 (2026-09-17)

> **주장.** 커넥톰에서 오는 것은 **배선 구조뿐이며 가중치는 학습된다.** 질문은 "초파리 배선 구조가 좋은 아키텍처 사전분포인가" 다.
> 정확한 표현은 "초파리 커넥톰 배선 제약을 가진 네트워크". "초파리가 테트리스를 학습했다" 류의 표현은 쓰지 않는다.
> 5단계까지의 음성 결과(`docs/stage5-separation.md`, `docs/stage6-versus.md`)는 **고정 가중치 체제에 한정된 결과**로 보고서에 그대로 둔다.

데이터: `data/stage7-c0.json` (Phase A), `data/stage7-results.json` (Phase B), `data/stage7-budget.json`, `data/stage7/c0.model.{bin,json}` (학습된 C0, Float32).
재현: `npm test` → `npm run estimate-budget` → `npm run train-c0` → (게이트 통과 시) `npm run train-nulls` → `npm run smoke`.

## 0. 왜 이 단계인가

6단계 결론: 랭킹 손실은 정상 작동하지만(원 보드 입력에서 top-1 +12–14%p, CI 분리) 고정 리저버의 DN 특징 위에서는 이득이 0 이다 —
원인 1(손실)의 기여 ≈ 0, **원인 2(고정 가중치의 표현력)가 지배적**. 참조점: 원 보드 200 셀 + 얕은 리드아웃 τ 0.31 / top-1 43%, 교사 자신의 특징 60%.
그래서 7단계는 커넥톰을 **희소성 마스크**로만 쓰고 가중치를 학습한다. 웹 대전 UI 는 8단계, 보고서는 9단계.

## 1. 모델과 확정 결정

**레이트 RNN** (`src/sparse-rnn.js`). 스파이킹 BPTT 는 주 경로에서 제외 (C0 게이트 통과 후 선택 과제).

```
x(t+1) = (1−lr)·x(t) + lr·tanh((W⊙M)·x(t) + W_in·u + b),   x(0) = 0,  lr 0.33,  T = 25 스텝 (입력 u 는 후보 하나의 afterstate — 창 동안 고정)
m = (1/T) Σ_{t=1..T} x(t)[DN 107]  →  z = (m − μ)/σ (초기 순전파 256 후보의 통계로 한 번 고정; 상수 DN 7개는 0)  →  s = MLP 107→64→1
```

- **M** 은 커넥톰 인접 마스크 (8,000 뉴런, 459,168 간선, 고정). **W** 는 M 이 1 인 위치에만 존재하는 파라미터 (희소 저장 — M=0 위치의 가중치는 애초에 없다;
  `test/stage7.test.js` 가 학습 후 밀집 복원으로 확인). 초기값 = 3단계 α=1 정규화(수신 뉴런 총 입력 weight 로 나눔)의 커넥톰 시냅스 수 × ρ_target/ρ_unit,
  ρ_target 1.0 (ρ_unit(α1) = 0.9997). **학습이 이 초기값에서 얼마나 멀어지는지 잴 수 있게 하려는 것이다** (§4).
- **W_in 도 학습한다** (2,316 입력 뉴런 × 256). 3단계 가우시안 RF 배정은 커넥톰에서 온 것이 아니라 임의 선택이고 README 에 한계로 명시돼 있다 — 고정하면 입구가 병목으로 남는다.
  초기값: 보드 200 열 = 그 RF (뉴런별 합 1) × 1.0, 나머지 56 열 = U(−0.1, 0.1). b (8,000) 는 0 에서 시작해 학습.
- **출력은 DN 107 유지** (생물학적 주장의 일부). 리드아웃 107→64→1 MLP (ReLU).
- 파라미터 수 **P = 1,067,041** = W 459,168 + W_in 592,896 + b 8,000 + 리드아웃 6,977.
- **입력 u (256)** = afterstate 보드 200 (0/1) + 놓은 조각 one-hot 7 + 놓은 회전 상태 one-hot 4 + 적용 후 hold 7+빈칸 1 + 적용 후 앞으로 올 조각 5×7 (current′ + next′[0..3])
  + 적용 후 가비지 큐 높이 min(1, 줄/8) + 적용 후 콤보 min(1, 콤보/10). 전 성분 [0, 1], 표준화 없음 (`meta.uNormalization`). **후보별 afterstate** 방식 유지 — 결정당 K 회 전방 계산.
- **손실**: 6단계 pairwise 힌지 (m = 1, top-1 근소 우위). listwise 는 Phase B 표에만.
- **K=8 학습 / 전체 후보 평가.** 학습 부분집합 = 교사 선택 + 교사 값 상위 7 (hard negatives). 평가 함수는 부분집합 표식이 있는 결정을 거부한다
  (K=8 로 평가하면 top-1 이 부풀려진다; `metricsFromScores` 가 throw). 테스트 집합은 6단계 rank-train 과 **같은 1,204 결정** (게임 0,4,6,11,28,29,30,31,45) — 6단계 표와 직접 비교.
- **강화학습 없음.** 교사(6단계 공격형, 377줄/생존 100%)가 라벨을 준다. 분포 이동은 DAgger 로 잡는다.
- **C2 weight-shuffle 삭제.** C2 는 "배선 그대로, 가중치만 순열" 이었다. 가중치를 학습하면 마스크만 남으므로 C2 의 마스크는 C0 와 **동일**하다 —
  같은 아키텍처를 두 번 학습하는 것이지 null 이 아니고, null 로 보고하면 오류다. 대신 **초기값 대조군** `C0-shuffled-init` (마스크 C0, 초기 W 만 간선 사이에서 순열)
  을 Phase B 에 보조로 넣었다 — "커넥톰 *초기값* 이 학습 결과에 기여했는가" 라는 별개의 질문에 답하기 위한 것이며 null 조건이 아니다.
- **하이퍼파라미터** (`src/stage7-train.js HYPER`, 전 조건 동일): Adam lr 1e-3 코사인 → 0 (ftLr 5e-4), 미니배치 32 결정, 전역 노름 클리핑 5, 라운드 0 ≤ 15 에폭 / patience 3,
  DAgger 재학습 ≤ 5 에폭 / patience 2 (warm start, Adam 상태 유지). lr 만 C0 에서 2 에폭 × 2,000 결정 파일럿으로 1e-3 vs 3e-4 를 봤다
  (val 0.600 vs 0.613, top-1 32.7 vs 31.3%, CI 겹침) — 기본값 1e-3 을 쓰고 모든 조건에 동일 적용. 조건별 튜닝은 없다.

## 2. 구현 — 배치 BPTT 커널과 예산

6단계 예산 추정(언롤 스텝당 7.0 ms, B 1, CSC 전치 역전파)으로는 결정 8k × K 8 이 4.4 h 였다. 두 가지로 **10배** 줄였다 (`src/sparse-rnn.js`):

1. **후보 배치**: 후보 B 개를 N×B 행렬(뉴런 행, 후보 열 연속)로 한 번에 돈다. 간선당 인덱스·가중치를 한 번 읽고 B 개 곱을 코드로 펼친다 (B 별 `new Function` 생성, 레지스터 호이스팅).
2. **전치 없는 역전파**: dW[e] = Σ_b dPre[post,b]·x[pre,b] 와 dx[pre,:] += w·dPre[post,:] 는 둘 다 pre 행에서 쓰므로 CSR 순서 그대로 돈다 — CSC·tpos 간접 참조가 없다.

실측 (`npm run estimate-budget`, `data/stage7-budget.json`): **결정 하나 BPTT (K 8 × T 25) 119 ms 단일 스레드 = 0.59 ms / 후보·스텝**, 후보 점수(순전파) 6.9 ms, 교사 라벨 88 ms/결정;
12 워커 병렬 배율 ×9.8 (Core Ultra 7 255H, 6P+8E). Phase A 기대 1.3–1.5 h / 상한 1.8–2.2 h (≤ 8 h), Phase B 9 실행 기대 4.4 h / 상한 6.4 h. 실제 Phase A 는 2.98 h 였다 (§7).
학습 루프는 데이터 병렬: theta 는 SharedArrayBuffer 하나를 12 워커가 읽고, 워커마다 자기 기울기 SAB 에 누적, 주 스레드가 합산 → 클리핑 → Adam → 같은 메모리에 갱신 (스텝당 ~1 s, 결정 32).
희소 W 의 BPTT 기울기는 작은 커넥톰(13 뉴런 · 30 간선 · T 6) 에서 모든 파라미터를 중심 유한차분과 대조한다 (상대 오차 < 1e-5, pairwise·listwise; `test/stage7.test.js`).

## 4. 학습된 W 는 커넥톰 초기값에서 얼마나 멀어졌나 (라운드 3 최종, `data/stage7-c0.json weights`)

초기값: 전 간선 흥분성, 평균 0.0172 (α=1 정규화 → 뉴런의 입력 합 1). Adam lr 1e-3 은 이 규모의 가중치에 스텝당 ~6% 다 — Adam 은 파라미터별로 기울기 크기를 정규화하므로

  시각 투사 뉴런(LC/LPLC)이 들어가는 시각 처리 영역이고, 가장 많이 바뀐 뉴런 10 개 중 7 개가 PVLP/AOTU/AVLP/LO 의 중간층 뉴런이다 (post 총 \|Δw\| 12–19, 입력 차수 240–630).
  기울기 신호가 일관되게 흐른 곳이 입력 경로였고, 버섯체(KC)·하강뉴런 직전 회로에는 일관된 신호가 거의 없었다는 뜻이다 — 6단계에서 "입구가 병목" 이라고 본 진단과 맞는다.
- 커넥톰 초기값이 의미 있었는지의 직접 증거로는 부족하다: 이 상관은 "초기값에서 출발한 Adam 이 어디를 움직였나" 이지 "초기값이 아니었으면 어땠나" 가 아니다. 그 대조군 (`C0-shuffled-init`, 마스크 같고 초기 W 만 순열) 은 Phase B 에 넣어 두었고 게이트 통과 전에는 돌리지 않았다.

학습 부분집합이 "교사 선택 + 상위 7" 이라 **명백히 나쁜 수(하위 34 개)는 손실에 한 번도 들어가지 않았고**, 그 수들의 점수는 제약이 없다.

## 7. 예상과 달랐던 점

- **비용이 10 배 싸졌다.** 6단계 추정 7.0 ms/후보·스텝 (B 1, CSC 역전파) → 실측 0.59 ms (후보 배치 + 전치 없는 역전파). 8k 결정 · K 8 은 6단계가 예산 때문에 고른 축인데 지금은 그 제약이 없다 — §5.3 (b).
  대신 실제 에폭은 추정 1.8 min 이 아니라 5 min 이었다: 12 워커 동기화 장벽 + E-코어 편차 + 주 스레드 기울기 합산 (1.07 M × 12).
- **학습 전 모델이 이미 top-1 24.5%** (우연 3.2%). 커넥톰 초기값 + RF 의 "채운 칸이 적은 보드가 활동이 낮다" 편향이 교사 선택(줄 지우기)과 우연히 맞는다. 6단계 고정 리저버의 학습된 리드아웃 16–20% 보다 높다 —
  6단계 dn 입력은 발화 수였고 여기서는 상태 창 평균이라 스케일이 다른 탓도 있다. 게이트 35% 를 읽을 때의 기준선이다.
- **top-1 은 통과했는데 플레이는 실패했다.** 결정 내 순위 정보가 생긴 것(τ 0.17, 고정 리저버 0.00–0.03)과 살아남는 것은 다른 문제였다 — 학습 부분집합 밖의 수들(§5.1).
- **DAgger 는 1 라운드에서 대부분의 이득을 냈고** 그 뒤 재학습은 매번 에폭 1–3 에서 val 최선을 찍고 과적합했다.
- **W 는 입구에서 바뀌었다.** input→hidden corr 0.26, W_in 보드 열 0.49 vs hidden→output 0.96, KC 0.97 (§4). 39% 의 간선이 억제성이 됐다.
- 밀집 2 층 MLP 로는 C0 의 P 와 정확히 같은 파라미터 수를 만들 수 없었다 ((H1+2) | (P−1+2·U_DIM+2) 조건, P = 1,067,041 이 그 경우) — 3 층 (703→665→627) 으로 맞췄다.
- `C1 degree-shuffle` 이 학습으로 되살아나는지는 Phase B 를 안 돌려 미확인.

예산 추정 7 s · Phase A 2.98 h (라운드 0 58.7 min = 11 에폭 × 5 min + 평가 6.6 min; DAgger 라운드 3 회 각 3–4 min 수집 + 12.6/40.9/27.5 min 재학습 + 6–7 min 평가) · 진단 1.2 min ·

## 9. 진단 (확정) 과 채택된 축

Phase A 에서 top-1 37.8% 와 테트리스 0 회의 공존은 **목적 불일치**다: 테트리스 빌드는 수십 수의 우물 유지를 요구하고 한 번의 이탈로 무너지는데, 정책 선택의 14% 가 학습 상태에서도
교사 값 하위 절반이었다 (분포 이동이 아니라 학습 신호 결함). top-1 만 올려서는 플레이가 따라오지 않는다 (§5.2 파일럿 40.9% / 조각 200 / 생존 0).

| (a) 음성 구성 mixed | **채택** — 교사 선택 + 상위 3 + 무작위 4 (K 8) | `trainingSubset(…, { mixed, hard: 3 })`, `HYPER.negatives` |

## 10. 조기 중단 규칙과 게이트 A-2

- **조기 중단** (`shouldStopDagger`): 라운드마다 같은 시드 5 게임(가비지 포함, 1000 조각 상한)의 조각 수를 재고, 라운드 r 의 개선 = 시드별 짝지은 차이 (pieces_r − pieces_{r−1}) 의 평균,
  부트스트랩 95% CI 가 0 을 포함하거나 음수면 "개선 없음". **2 라운드 연속 개선 없음이면 남은 라운드를 건너뛰고 최종 평가로** 간다. (Phase A 의 라운드 2 이후 정체 반복 방지.)
- **게이트 A-2** (전체 후보 테스트 1,204 결정; 20 게임 × 1000 조각, **가비지 주입 0.08/조각 포함**, 교사 평가와 같은 시드): top-1 ≥ 40% · 조각 수 중앙값 ≥ 400 · 공격 라인 중앙값 ≥ 60 ·
  테트리스/게임 중앙값 ≥ 1 · 정책 선택의 교사 값 하위 절반 비율 ≤ 5%. 전부 통과해야 Phase B. 근거: 공격 150 은 빔 깊이 3 + hold + next 5 를 쓰는 교사 377 의 40% 였고 1-ply 에 그 비율을 요구할 근거가 약했다;
  생존율 70% 는 가비지 수신 1000 조각 기준이라 과했다 → 조각 수 중앙값으로 대체. "하위 절반 선택률" 은 순위 = 교사 값이 선택보다 큰 후보 수 (동점은 불리하게 세지 않음) 로 정의 (`metricsFromScores`).
- **우물 유지 길이**: 배치 뒤 보드의 `wellDepth ≥ 2` (한 열이 나머지 열의 최솟값보다 2 이상 낮음) 인 연속 배치 구간(run)의 길이 분포와, 구간 안에서 테트리스가 났는지를 기록한다 (`playSoloTracked`).

## 11. 구현 변경 — WASM SIMD 커널

Phase A 의 실측 에폭(8k, 5.3 min)은 이상치(단일 스레드 비용 / 병렬 배율 = 1.9 min)의 2.9 배였다 — 12 워커가 동시에 W (3.7 MB) + 인덱스 (1.8 MB) 를 스텝마다 스트리밍하면 메모리 대역폭에 걸린다.
희소 matvec 두 개와 역전파의 원소별 단계를 **WebAssembly SIMD (f64x2)** 로 옮겼다 (`src/wasm-kernels.js`, 외부 도구 없이 바이너리 직접 조립; tanh 는 JS). 커널 배열은 WASM 메모리 안에 두고 JS 는 뷰로 접근한다.
결과는 JS 커널과 덧셈 순서 차이(≤ 1e-18) 안에서 같다 (테스트). 12 워커 경합 상태 실측: 결정당 BPTT 325–423 ms → 199–223 ms, 후보 점수 20–26 ms → 11–13 ms (×1.6–1.9). 기본 백엔드 = wasm (`SPARSE_RNN_BACKEND=js` 로 되돌림).
λ 파일럿은 JS 백엔드로 돌았고 본 학습부터 wasm — 수치적으로 동등한 알고리즘이다.
