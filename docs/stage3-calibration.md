# 3단계 — 동역학 수리 + 캘리브레이션 v2 결과 (2026-09-15)

데이터: `data/spectral.json`, `data/calibration.json` (스파이킹, 전 탐색점), `data/calibration-esn.json` (Plan B).
재현: `npm run spectral && npm run calibrate && npm run calibrate-esn && npm run smoke` (시드 2026, 결정적).

## 1. 스펙트럼 반경과 2단계 절벽의 대조

| alpha | rho_unit | 임계 g = 1/rho_unit | 수렴 |
|---|---|---|---|
| 0.5 | 59.2196 | 0.0169 | 39회, 예 |
| 1.0 | 0.9997 | 1.0003 | 94회, 예 |

2단계에서 관측한 절벽은 g ≈ 0.07 (alpha 0.5) = **rho ≈ 4.0**. 선형 스펙트럼 판정(rho = 1)은 절벽을 4배 낮게 예측한다.
문턱·누설·불응기가 있는 LIF 에서는 단위 시냅스 입력당 스파이크 이득이 1보다 훨씬 작아 선형화가 보수적이기 때문이다.
진단 1("절벽 = 스펙트럼 반경 1")은 **방향은 맞고 수치는 틀렸다.** 결과적으로 스펙의 rho_target ∈ [0.8, 1.3] 은
중간층이 거의 침묵하는 영역(median 0 Hz, 발화 DN 1–7개)이라, rho ≤ 5.0 확장 탐색을 별도 표기로 추가했다. 하드 제약은 그대로다.

## 2. 하드 제약 통과 영역

| 탐색 | 점 | 통과 | 비고 |
|---|---|---|---|
| 스펙 범위 rho ∈ [0.8, 1.3] | 1200 | **0** | 전부 침묵 (median 0 Hz) |
| 확장 rho ∈ [0.8, 5.0] | 1200 | **4** | 전부 alpha 1, rho 4.06–4.94, k_local ≤ 0.33, b 0.35–1.81 |
| 부분: b = 0 고정 | 300 | **0** | median ≥ 0.5 Hz 인 점 0개 |
| 부분: k_local = 0 고정 | 300 | **29** | alpha 1 & rho ≥ 3.3 인 65점 중 29 (45%); alpha 0.5 는 0 |

탈락 사유는 폭주가 아니라 **침묵**이다: 확장 탐색 1200점에서 ceilingFrac 제약은 100% 통과, topSpikeShare 99.5% 통과,
median ≥ 0.5 Hz 는 0.3%, 발화 DN ≥ 40 은 1.0% 만 통과. k_local 이 0.5 를 넘는 점(표본의 96.5%)은 예외 없이 침묵한다
(k_local 0–0.5: 42점 중 4 통과, 0.5 이상: 1158점 중 0). 즉 스펙의 k_local ∈ [0, 20] 은 유효 범위보다 약 50배 넓다.

**alpha**: alpha 0.5 는 k_local = 0, rho ≤ 5 에서도 통과점이 없다 (mean 1–3 Hz, median 0). SFA 를 조금이라도 넣으면
절벽 위(rho ≈ 4) 의 폭주가 침묵으로 무너지고 중간 영역이 생기지 않는다. alpha 1 (수신 뉴런 총 입력 가중치 정규화) 은
허브가 불균형한 구동을 받지 못하게 해 rho 3.3–5 에서 넓은 안정 영역을 만든다.

## 3. SFA vs 지역 억제 — 승자독식을 깬 것은 SFA

- b = 0 (SFA 없음), alpha 1, k_local < 0.6, rho ≥ 3.9: mean 12–51 Hz 인데 **median 0 Hz**, DN 38–46 — 절반의 뉴런이 침묵하고
  나머지가 높게 발화하는 양극화 상태. 승자독식이 뉴런 수준에서 그대로 남는다.
- 같은 영역에 b 0.2–1.8 을 넣으면 median 2–25 Hz, 활성 30–41%, topSpikeShare 2–4% 로 활동이 퍼진다.
- 지역 억제는 k_local > 0.5 에서 네트워크를 통째로 끄고, 그 아래에서는 있으나 없으나 같다 (통과점 33개 전부 k_local ≤ 0.33).
  ROI 풀은 입력층(LO(R) 631개)이 자기 자신을 억제하는 효과가 커서 공급을 끊는다.

선택은 사실상 잡음이다. **최종 게이트(+10%p) 미달 → Plan B.**

## 5. 게이트는 달성 가능한가 — 원 입력 참조 프로브

같은 릿지 프로브를 리저버 대신 **원 입력(보드 200셀 + 조각 one-hot 7)** 에 적용했다:

| 보드 | top-1 | 통제 | 마진 | 다수 기준선 | 특징 R² |
|---|---|---|---|---|---|
| 200 | 14.0% | 13.5% | +0.5p | 10.0% | 0.565 |
| 2000 | 19.1% | 14.8% | **+4.3p** | 14.0% | 0.609 |

교사(Dellacherie)의 행동은 보드의 강한 비선형 함수라 **원 입력에서도 선형 리드아웃은 +4.3p 가 한계**다. 따라서 +10%p 게이트는
어떤 리저버 표현으로도 선형 프로브로는 넘을 수 없다. 이 게이트의 미달은 리저버의 결함이 아니라 프로브 (b) 가 과제에 대해
잘못 설정된 것이며, 4단계 학습(비선형 또는 다층 리드아웃, 혹은 특징 공간 회귀)의 성공 여부를 예측하지 않는다.
의미 있는 비교는 프로브 (a) 특징 R² 다: 원 입력 0.61, 스파이킹 선택점 0.51, ESN 0.50–0.60 (§7).

## 6. gap 축

상위 20점의 gap 분포: 0 → 5, 25 → 2, 50 → 8, full → 5. top-1 로는 구분이 안 되지만 **특징 R² 는 gap 이 결정한다**:

| gap | 점 | 특징 R² 평균 | mean Hz |
|---|---|---|---|
| 0 | 5 | 0.134 | 10.2 |
| 25 | 2 | 0.146 | 8.3 |
| 50 | 8 | 0.144 | 12.6 |
| **full** | 5 | **0.483** | 26.8 |

완전 리셋에서만 DN 발화율이 보드 특징을 담는다 (0.45–0.51, 원 입력 0.61 에 근접). 25–50 스텝 감쇠 구간은 리셋에 수렴하지
않는다 — 지속 어트랙터가 그보다 오래 남는다. 2단계의 "배치 간 리셋 없음" 결정은 표현력을 3배 이상 깎고 있었다.

## 7. Plan B — ESN (같은 CSR, 누설 레이트 유닛)

발동 이유: 스파이킹 선택점의 게이트 마진 +1.3p < +10p. `scripts/calibrate-esn.js`, 240점(보드 200) → 상위 10점(보드 2000).
탐색축 rho ∈ [0.8, 1.3], lr ∈ [0.05, 1], 입력 스케일 ∈ [0.5, 50] (로그 균등), alpha, gap. 하드 제약: 포화(|x| > 0.9) < 5%,
활성 DN ≥ 40, **분리도 ≥ 0.01** (1차 실행에서 입력과 무관한 고정점 — 모든 보드가 같은 DN 상태, 분리도 0.000 — 이 top-1 잡음으로
선택되고 릿지가 리셋 직후 과도 표본에 외삽해 R² −10⁴ 를 냈다. 분리도 제약과 프로브의 z ±5 winsorize 로 막았다).

| 항목 | 값 |
|---|---|
| 통과 | 39/240 (alpha 0.5: 32/110, alpha 1: 7/130). 탈락 사유는 분리도(18% 만 통과) — alpha 1 은 rho ≥ 1 에서 tanh 고정점으로 붕괴 |
| 선택점 | rho 1.2074, alpha 0.5, lr 0.329, 입력 스케일 7.17, gap 50 (g = 0.0204) |
| 상태 | mean\|x\| 0.136, 포화 0.0%, DN 100/107, 분리도 0.034, 랭크 52 |
| 프로브 (b) | top-1 **15.5%** vs 통제 14.2% (**+1.3p**) — 상위 10점 전부 14.8–15.5% vs 14.0–14.2% |
| 프로브 (a) | 특징 R² 0.503 vs 통제 0.558 (상위 10점 대부분 0.59–0.60 vs 통제 0.50–0.56); landingHeight 0.91, colTrans 0.86, holes 0.68, wells 0.64 |
| 비용 | 64 ms/배치 (희소 행렬곱 + tanh 8000, 워커 8 동시) |
| 게이트 | **미달** (+1.3p) |

**해석**: 스파이킹(+1.3p, R² 0.51) 과 레이트(+1.3p, R² 0.50–0.60) 모델이 같은 결과를 냈고, 원 입력(+4.3p, R² 0.61) 도 게이트를
못 넘는다. 따라서 "실제 커넥톰 위상이 LIF 스파이킹 체계에서는 디코딩 가능한 표현을 못 만든다" 는 결론은 성립하지 않는다 —
프로브 (b) 는 어느 표현에서도 우연 수준이고, 특징 R² 로는 세 표현이 0.5–0.6 으로 비슷하다.
셔플 통제군의 R² 도 높다(0.45–0.56)는 점에 주의: 표본별 순열은 활동량 분포를 남기고, 보드 채움 정도가 holes·height 와 상관하므로
"뉴런 정체성이 담는 정보" 는 원 입력 +0.04, 스파이킹 +0.06, ESN −0.06~+0.09 로 모두 작다. 4단계 학습이 성공하려면 리드아웃이
DN 정체성 코드가 아니라 활동량·비선형 조합을 써야 한다는 뜻이다.

## 8. 처리량

smoke (선택점, gap full, 500조각, 단일 스레드, 다른 부하 없이): **660 배치/s** — encode 0.15 ms, reservoir 1.33 ms, decode 0.01 ms
(ESN 탐색과 동시 실행 시 400 배치/s).
플레이 중 평균 발화율 15 Hz (랜덤 리드아웃의 보드는 캘리브레이션 보드보다 비어 있다). 불법 배치 0, 도달불가 DN 7개 발화 0.
캘리브레이션 처리량: 스파이킹 1200점 ≈ 100–120 s (워커 8), 전체 파이프라인 6분; ESN 240점 ≈ 10분, 전체 16분.

## 9. 구현 메모 (스펙과 다르게 한 것)

- **SFA 단위**: a_i 를 스텝당 전류로 빼면 τ_m 만큼(20배) 과강해져 b = 0.5 로도 네트워크가 죽는다. 막전위가 V_rest − a_i 로
  이완하는 exponential-Euler 형(스텝당 −a_i(1−e^{−dt/τm}))으로 구현했고, b ∈ [0, 2] 는 이 단위에서 의미가 있다.
- **SFA lazy 평가**: 적응 전류는 매 스텝 V 갱신에 들어가므로 "마지막 갱신 스텝 기록 후 닫힌형 보정"으로 미룰 곳이 없고,
  닫힌형 pow 는 naive 곱셈열과 비트가 어긋난다. 대신 증분·감쇠·소거를 a ≠ 0 목록에만 하는 이벤트 구동으로 했고 밀집 루프는
  aVal 을 한 번 읽는다. `a < b·1e-4 → 0` 소거 규칙을 모델에 포함해 naive 매스텝 갱신과 2400 스텝 비트 일치를 테스트한다.
- **확장 탐색**: §1 의 이유로 rho ≤ 5.0. 스펙 범위 결과는 그대로 `search` 에, 확장은 `extended` 에.
- **프로브 비용**: 릿지 5-fold × 내부 4-fold × λ 6 은 점당 ~2 s 라 탐색 중에는 하드 제약 통과점에만 프로브를 돌린다
  (선택에 필요한 것은 그것뿐). 재평가 20점은 전부 프로브.
- **원 입력 참조 프로브** (§5) 는 스펙에 없지만 게이트 해석에 필수라 추가했다 (`inputReference`).
- **ESN 하드 제약**: 포화(|x| > 0.9) < 5%, 활성 DN ≥ 40 — 스파이킹 제약의 대응. 1차 실행에서 DN 상태가 상수인 퇴화점이
  top-1 잡음으로 선택되고 릿지 표준화가 R² −229 로 터져서, 열 표준편차 상대 바닥(1e-8), 표준화 값 ±5 winsorize,
  분리도 ≥ 0.01 제약을 추가했다 (스파이킹 상위 20점의 분리도 최소는 0.35 라 영향 없음).
- **병렬화**: `scripts/calibrate-worker.js` (worker_threads). 점 추출은 메인 스레드가 시드 하나로 하므로 워커 수와 무관하게 결정적.
