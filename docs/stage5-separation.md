## 1부 — 분리 동작점 탐색 (C0, 600점, 11.2 min, 상한 3 h)

### 지표 (`src/separation.js`)

같은 결정의 후보 afterstate 들(보드가 완전히 같은 후보 — O 의 4 회전, S/Z/I 의 2 회전 — 는 하나로 합침; 34 → 21 개/결정)을
후보마다 완전 리셋으로 리저버에 넣고: `distinctFrac` 서로 다른 DN 발화 수 벡터 비율, `meanDNDiff` 후보 쌍 간 발화 수가 다른 DN 수,
전파 프로파일(쌍 간 발화 수가 다른 뉴런 수: 입력 / 중간 / DN), `withinKendall` 결정 내 중심화 릿지(훈련 결정 100)의 테스트 결정 50 켄달 τ.

**4단계 §3 의 정정.** 4단계의 "입력 52 → 중간 0.6 → DN 0.13" 은 테스트 분할의 *처음* 25개 결정(초반의 거의 빈 보드)에서 잰 것이라
대표성이 없었다. 테스트 결정을 셔플해 50개로 재면 같은 4단계 C0 동작점에서 distinct 70%, dnDiff 30/107, 프로파일 736/1163/30 이다.
분리는 보드 채움에 따라 양극단이다: 채움 ≤ 26 셀이면 3–6% / 0 DN (문턱 아래, 침묵), 48 셀 이상이면 50–100% / 30–70 DN
(중간층 1,000–3,000 뉴런이 달라지는 증폭). 어느 쪽이든 결정 내 τ ≈ 0 이다 — 아래 1부 결과가 이를 전 범위에서 확인한다.

**가설("낮은 rho·강한 SFA·짧은 창이 임계점 근처에서 섭동을 살린다")은 기각된다.** 분리는 rho·G_IN·T 모두에서 단조 증가하고,
낮은 rho 는 임계점이 아니라 침묵(median 0 Hz 인 560점 중 distinct 17%)이다. 강한 SFA(b 2–3)는 분리를 *줄이며*(17%), 짧은 창은
dnDiff 를 줄인다(T 25: 1.4 vs T 100: 4.3). 분리는 곧 활동량이다: median > 0.5 Hz 인 35점은 전부 distinct 84–93%.
그리고 활동이 많을수록 중간층 차이(700–1,400 뉴런)는 커지지만 τ 는 여전히 0 — 증폭이 정보를 담지 않는다.

**alpha 0.5 는 분리 제약 하에서 살아나지 않는다** (0/295): rho ≤ 5 에서 SFA 와 함께 두면 침묵으로 무너진다 (3단계와 같은 이유).
따라서 "alpha 0.5 의 rho_unit 이 조건 간에 벌어지는가" 는 이 동작점에서는 측정 대상이 아니고, 2부의 rho_unit 표(alpha 0.5 열)는
조건 그래프의 구조 지표로만 보고한다.

## 3. 결론과 해석

1. 5단계가 겨냥한 "분리 부재" 는 4단계 진단의 표본 편향이었다. 분리는 활동만 있으면 나온다 (제약 통과 16/17). **없는 것은 순위 정보다**:
   전 탐색 600점·전 조건에서 결정 내 τ ≤ 0.075. 임계점 가설은 기각 — 낮은 rho 는 침묵이고, 분리는 활동량과 단조다.
2. 중심 질문에 대한 답은 지표에 따라 다르다: 풀링 R² 에서는 C0 가 null 위(+0.03~0.13), C6 대비 +0.055 로 실제 배선의 DN 코드가 활동량
   이상의 보드 정보를 담는다. 결정 내 순위·플레이에서는 차이 없음. **가장 강한 null 대비 차이는 동작 영역의 존재 자체다**: 차수 보존 재배선은
   같은 제약에서 켜지지 않는다.
3. 플레이 성능은 전 조건 무작위 수준이다. 이 정식화(afterstate → 완전 리셋 25 ms 창 → DN 발화 수 → 가치)는 결정 내 순위를 담지 못한다.
